# 변경 내역

## 2026-09-29

- Django 5.2 LTS 및 운영/개발 의존성 분리, 환경변수 예시와 배포·복구 문서 추가
- 저장형 XSS 경로 제거: JSON은 json_script, 동적 단어 출력은 textContent
- 요청 UUID 멱등 채점, 트랜잭션, 낙관적 버전 검사, 서버 상태 기반 정답 인정
- 사용자-단어 고유 제약 및 기존 중복 연결 병합 마이그레이션
- API 400/401/404/409 응답, CSRF/세션 만료 안내, 연타·지연 응답 방지
- 개인 단어 수정, 검색·필터·페이지 나누기, 일시정지, 학습 목록 제외
- 영어 모드, 추가 정답, 태그·메모, 문제 수·신규/복습 선택, 성조 시험
- 같은 탭 이어하기, 결과 요약, 플래시카드 전체 보기, 기기 음성 재생
- CSV 미리보기/검증/확인 저장/내보내기 및 수식 삽입 방지
- 오전 4시 학습일 통일, 복습 간격 상한, 프로세스별 통계 캐시 제거
- POST 로그아웃, 안전한 next URL, DB 기반 로그인 제한, 비밀번호 변경
- Bootstrap·Font Awesome을 라이선스와 함께 자체 제공하여 외부 CDN 의존 제거
- 생성된 정적 자산을 Git 추적에서 제외; 오래된 결과 템플릿 제거
- 백엔드·상태 전이·기존 DB 마이그레이션 테스트와 CI 추가

## 범위와 제한

- 운영 서버에 배포하거나 실제 사용자 DB를 변경하는 작업은 포함하지 않습니다.
- 자동 병음 생성/AI 의미 채점, 이메일 비밀번호 재설정, 계정 삭제, 기기 간 이어하기, PWA, 다크 모드는 구현하지 않았습니다. 외부 서비스·데이터 삭제 정책·추가 UX 결정이 필요한 확장 항목입니다.
- CSV 가져오기는 신규 학습 항목 추가용입니다. 기존 개인 데이터 덮어쓰기, .xlsx, 복습 기록 복원은 지원하지 않습니다.
- 전체 퀴즈/플래시카드의 1회 로딩 상한은 1,000개입니다. 나머지는 이후 세션에서 학습합니다.
- SQLite를 유지합니다. 동시 쓰기 충돌은 409로 안내하고 같은 요청 ID로 재시도합니다. 다수 사용자가 동시에 학습하는 규모라면 PostgreSQL 이전과 부하 검증이 필요합니다.
- API 자체 학습 기록 수정 방지를 강화했지만 이 앱은 시험 감독·부정행위 방지 시스템이 아닙니다.
- 공용 사전에 신규 항목을 등록할 수 있습니다. 기존 공용 항목의 일반 사용자 수정은 허용하지 않습니다.
- 공개 저장소의 오픈소스 라이선스는 소유자가 선택해야 하므로 임의로 추가하지 않았습니다.
